# نظام إدارة الأقساط

نظام متكامل لإدارة أقساط العملاء مع إمكانية إرسال إشعارات تلقائية عبر واتساب.

## المميزات

- إدارة العملاء وأقساطهم
- إرسال إشعارات تلقائية عبر واتساب
- تتبع حالة الدفع
- واجهة مستخدم سهلة الاستخدام
- دعم اللغة العربية
- حفظ البيانات في ملف CSV

## متطلبات التشغيل

- Python 3.13
- المتطلبات التالية:
  - customtkinter
  - Pillow
  - pandas
  - selenium
  - webdriver_manager
  - arabic-reshaper
  - python-bidi

## طريقة التشغيل

1. قم بتثبيت Python 3.13 من [الموقع الرسمي](https://www.python.org/downloads/)
2. قم بتثبيت المتطلبات باستخدام الأمر:
   ```
   pip install -r requirements.txt
   ```
3. قم بتشغيل البرنامج باستخدام ملف `simple_build.bat`

## الملفات المهمة

- `The-Project.py`: الملف الرئيسي للبرنامج
- `simple_build.bat`: ملف تشغيل البرنامج
- `requirements.txt`: ملف متطلبات البرنامج

## كيفية الاستخدام

1. **إضافة عميل جديد**:
   - انقر على زر "إضافة عميل"
   - أدخل بيانات العميل
   - حدد عدد الأقساط وقيمتها

2. **إدارة الأقساط**:
   - اختر العميل من القائمة
   - يمكنك تعديل أو حذف الأقساط
   - يمكنك تحديد الأقساط المدفوعة

3. **إرسال إشعارات**:
   - يتم إرسال الإشعارات تلقائياً قبل موعد الدفع بثلاثة أيام
   - يمكنك إرسال إشعارات يدوياً من خلال قائمة "إرسال إشعارات"

## ملاحظات مهمة

- تأكد من وجود اتصال بالإنترنت عند إرسال الإشعارات
- يجب أن يكون لديك حساب واتساب ويب مسجل على جهازك
- يتم حفظ البيانات تلقائياً في ملف CSV
