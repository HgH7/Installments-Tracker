# Installments Manager

This is a standalone application for managing customer installments.

## Contents
- Installments Manager.exe: Main application executable
- customer_files/: Directory for customer-related files
- backups/: Directory containing backup files
- logs/: Directory containing application logs
- customers.csv: Customer database
- PyWhatKit_DB.txt: WhatsApp integration database

## Usage
1. Double-click Installments Manager.exe to start the application
2. All data will be automatically saved in the respective folders
3. Backups are created automatically
