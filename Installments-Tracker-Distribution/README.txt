Installments Tracker - Installation Instructions

1. Extract all files to a folder of your choice
2. Double-click Installments-Tracker.exe to run the program
3. The program will create necessary folders automatically

Important Notes:
- Keep all files in the same folder
- Do not delete any of the included folders
- The program will create backups automatically
- Customer files are stored in the customer_files folder
- Logs are stored in the logs folder
